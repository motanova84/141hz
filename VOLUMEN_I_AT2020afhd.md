## Apéndice A: Detalles Técnicos del Análisis

### A.1 Método Lomb-Scargle

El periodograma Lomb-Scargle es ideal para datos astronómicos no uniformemente muestreados:

```
P_LS(ω) = (1/2σ²) × [ (Σ(y-ȳ)cos(ωt))² / Σcos²(ωt)  +  (Σ(y-ȳ)sin(ωt))² / Σsin²(ωt) ]
```

**Ventajas:**
- No requiere muestreo uniforme
- Robusto frente a gaps en datos
- Proporciona estimación directa de significancia estadística

### A.2 Cálculo de Errores

**Bootstrap:**
1. Remuestrear datos con reemplazo (1000 iteraciones)
2. Recalcular periodo en cada iteración
3. Error = desviación estándar de la distribución bootstrap

**Propagación:**
```
σ(f₀/f_frame) = (f₀/f_frame) × √[(σ_f₀/f₀)² + (σ_frame/f_frame)²]
```

### A.3 Ajuste del Modelo Ψ

**Función de costo:**
```
χ² = Σᵢ [(yᵢ - Ψ(tᵢ))² / σᵢ²]
```

**Minimización:**
- Método: Levenberg-Marquardt
- Inicialización: Amplitud desde LSP, fase desde correlación cruzada
- Convergencia: χ² < χ²_crítico (95% confianza)
