┌────────────────────────────────────────────────────────────────────────────┐
│ SOLUCIÓN MATEMÁTICA                                                        │

│                                                                            │
│  1. DEMOSTRACIÓN DE ADIMENSIONALIDAD DE A_eff                             │
│     ──────────────────────────────────────────                            │
│     A_eff = palabras_únicas / palabras_totales                            │

│  2. CONSISTENCIA DIMENSIONAL DE Ψ                                         │
│     ─────────────────────────────────                                     │
│     [Ψ] = [I · A_eff²]                                                    │
│         = [I] · [A_eff²]                                                  │
│         = [I] · [1]²                                                      │
│         = [I]                                                             │

│     ∴ Ψ hereda las dimensiones de I (bits, nats, etc.)                    │
│     ∴ NO hay ruptura dimensional                                          │

│  3. COMPORTAMIENTO LÍMITE                                                 │
│     ─────────────────────                                                 │
│     lim(A_eff→1) Ψ = lim(A_eff→1) [I · A_eff²]                           │

│                    = I · 1²                                               │
│                    = I                                                    │
