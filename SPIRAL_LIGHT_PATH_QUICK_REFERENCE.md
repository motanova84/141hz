## API Reference

### SpiralLightPath

**Methods:**
- `get_zeta_zeros(n)` - Get first n Riemann zeta zeros
- `get_primes(n)` - Get first n prime numbers
- `compute_prime_phase(idx)` - Phase shift from prime
- `spiral_trajectory(t, prime_index, include_3d)` - Compute spiral path
- `zeta_modulated_wavefunction(x, t, n_modes)` - Wave function Ψ(x,t)
- `interference_pattern(x, t, n_modes)` - Intensity |Ψ|²
- `compute_spiral_deviation(t, prime_index)` - Deviation metrics
- `critical_line_projection(t, prime_index)` - Observer view
- `evolution_operator(t, n_modes)` - Quantum evolution U(t)

### SpiralParameters

**Attributes:**
- `f0`: Fundamental frequency (default: 141.7001 Hz)
- `r0`: Initial radius (default: 1.0)
- `lambda_fractal`: Expansion index (default: 0.01)
- `precision`: mpmath precision (default: 50)
