## 📊 API Reference

### `QuantumHarmonicUnifier`

Main class for quantum harmonic unification analysis.

#### Constructor

```python
QuantumHarmonicUnifier(f0=141.70001, precision=50)
```

**Parameters**:
- `f0` (float): Fundamental frequency in Hz (default: 141.70001)
- `precision` (int): Decimal precision for mpmath calculations (default: 50)

#### Methods

##### `musical_octave_position() → Dict`

Calculate musical octave relationships.

**Returns**: Dictionary with:
- `note`: Musical note name
- `octaves_below_middle_c_sharp`: Position relative to middle C#
- `ratio_to_middle`: Frequency ratio
- `description`: Human-readable summary

##### `prime_17_resonance() → Dict`

Calculate prime 17 resonance.

**Returns**: Dictionary with:
- `coupling_constant`: log(f₀) / 17
- `equilibrium_17`: Equilibrium function value
- `resonance_factor`: f₀ / 17

##### `riemann_zero_coupling() → Dict`

Calculate Riemann zero coupling.

**Returns**: Dictionary with:
- `riemann_zero_1`: First Riemann zero
- `f0_to_zero1_ratio`: Scaling factor
- `spectral_density_at_f0`: Zero density at f₀

##### `qcd_harmonic_structure() → Dict`

Calculate QCD color-flavor harmonics.

**Returns**: Dictionary with:
- `colors`, `flavors`, `gluons`: Component counts
- `color_frequency_hz`, etc.: Component frequencies
- `qcd_dimension`: Total dimensional space
- `octaves_to_qcd_scale`: Distance to confinement scale

##### `primordial_silence_frequency() → Dict`

Calculate primordial frequency scales.

**Returns**: Dictionary with:
- `planck_frequency_hz`: Planck scale frequency
- `cmb_frequency_hz`: CMB temperature frequency
- `octaves_to_planck`, `octaves_to_cmb`: Octave separations

##### `dreaming_universe_coherence() → Dict`

Calculate universal coherence.

**Returns**: Dictionary with:
- `psi_universe`: Total coherence factor (0-1)
- `golden_coupling`: Ψ × φ
- `coherence_level`: 'HIGH', 'MODERATE', or 'LOW'
- `components`: Individual component dictionaries

##### `generate_full_report() → Dict`

Generate complete analysis report.

**Returns**: Comprehensive dictionary with all analyses and summary.
